## [0.2.2] - 2026-11-23

### Исправлено
- Учёт статистики объявлял себя законченным, пока история ещё читалась: любой непрочитанный файл меньше 4 МБ считался разобранным. В окне это выглядело так: месяц $4 770 · 249 ч вместо полных цифр и без строки «считаю историю». Теперь учёт закончен, когда непрочитанного меньше 16 МБ, не считая расшифровок, которые дописываются прямо сейчас. Признак пересчитывается на каждом тике, поэтому неверная отметка в уже записанном файле учёта снимется сама.

### Изменено
- README по образцу mod-weather: снимок панели, раздел «Сколько вы экономите», погода с гифкой и пример карточки остывшего кеша.

## [0.2.1] - 2026-11-23

### Исправлено
- При включённом моде context-weather оба мода придерживали Enter на остывшем кеше по очереди, и сообщение уходило только с третьего нажатия. Теперь Stukach в этом случае уступает: придерживает и предупреждает только context-weather (по `enabledPlugins` в настройках).

## [0.2.0] - 2026-11-23

### Добавлено
- Погода контекста первой строкой панели: заполнение контекста, токены, лимиты «5ч» и «неделя», стоимость сессии, время жизни кеша — перенесена из мода context-weather 0.2.0 вместе с предупреждением об остывшем кеше (первый Enter называет цену перечитывания, второй отправляет).
- Статистика: за неделю лимита и месяц подписки — сколько стоила бы работа всех сессий и помощников по ценам Claude API, во сколько раз это больше цены подписки, сколько часов отработали агенты (в рабочих днях по 8 ч). По нажатию — история по месяцам и неделям с графиками; на терминале — полосами текста.
- Учёт статистики в `~/.claude/stukach/stats.json`: первый проход по всей истории идёт фоном, дальше дочитывается только новое; итоги переживают удаление расшифровок через 90 дней. Ведёт одно окно, остальные читают.
- Шестерёнка ⚙: галочки «Погода контекста», «Статистика», «Помощники» и цена подписки; настройки общие для всех окон.
- Кнопка «👥 Помощники» над полем ввода, пока панель закрыта.

## [0.1.2] - 2026-11-23

### Исправлено
- Панель, открытая из сессии, которую запустил оркестратор, показывала только эту сессию: семья искалась в папке одного проекта, а оркестратор и его сессии работают в разных папках (оркестратор в ClaudSoul, сессия мода — в папке мода). Теперь семья ищется по всем проектам, у каждой сессии берётся её собственная папка.

## [0.1.1] - 2026-11-23

### Исправлено
- Помощники волн (инструмент Workflow) не были видны: мод читал только `subagents/agent-*.jsonl`, а помощники волн лежат в `subagents/workflows/<волна>/`. Теперь они стоят под своей волной с её именем и числом идущих; законченные берутся из журнала волны.
- «Фоном идёт: … (498 720 ч)»: за фоновый запуск принималась копия запроса к модели (`api-request-blob`), в которой нет времени, — отсчёт шёл от 1970 года. Теперь запуск берётся только из ответа модели, а незнакомое время пишется как «время запуска неизвестно».
- Фоновый запуск, отклонённый стражем, и команда, остановленная принятым TaskStop, больше не числятся идущими; отклонённый TaskStop команду не снимает; запись запуска, переписанная в расшифровку после конца, команду не воскрешает.
- Помощник волны, упавший на лимите (`failed` в журнале), и помощники кончившейся волны (`workflows/<волна>.json`: completed, killed, failed) больше не «работают». Имя волны берётся оттуда же, если сценарий лежит не в `workflows/scripts`.
- Недописанный файл помощника или волны больше не роняет всю панель («Не прочитать сессии»).
- Помощник, ждущий разрешения, всегда в видимых строках, а не за пределом; малый вид панели считает всех идущих помощников, а не только показанных.
- До первого ответа помощника модель берётся из заказанной (`model`), а не из `pickedEffortModel`, которое расходится с настоящей моделью в 174 случаях из 271.

### Изменено
- Закончивший помощник уходит из списка сразу; под сессией остаётся строка «✓ закончили: N».
- Предел 8 строк — теперь на работающих помощников в группе (сессия или волна), остальные показаны числом «…и ещё работают: N».

## [0.1.0] - 2026-11-22

### Добавлено
- Панель «Помощники»: сессия-оркестратор, запущенные ею сессии и помощники каждой сессии.
- У помощника: роль значком, модель, последнее действие, состояние (работает, ждёт разрешения, закончил).
- У сессии: фоновые команды, которые ещё идут после конца хода.
- Нажатие на название сессии открывает её в приложении (Mac).
- Команда `/stukach` открывает панель заново.
